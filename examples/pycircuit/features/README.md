# Feature examples

These examples isolate a specific frontend, hierarchy, state, memory, trace, or
diagnostic contract. They are public usage examples and executable gate inputs,
not ad hoc regression files.

Performance harnesses are kept out of the example tree. For example, the
FastFwd authoring and simulation case lives here, while its longer-running C++
workload and parameter sweep live under
[`benchmarks/pycircuit/fastfwd`](../../../benchmarks/pycircuit/fastfwd/README.md).
