# Primitive API status

This reference formerly listed the CycleAwareSignal and handwritten C++/Verilog
primitive library. Those APIs and recipes are retired from the active product
route.

The current profile provides finite scalar state and supported scalar
expressions through function modules and nested rules. Public queue, memory,
CDC, clock, and backend primitive APIs are not part of the approved slice.
Unsupported operations fail closed. See the
[language reference](language.md) and [M5 migration guide](../development/m5-migration.md).
