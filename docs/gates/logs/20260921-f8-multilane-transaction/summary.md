# F8 multi-lane transaction algebra

## Decision

- Decision 0280 defines one explicit bounded lane-mask algebra for multi-lane
  rules: `ac.reservation_set` (preview or committed), `ac.transaction_group`
  with the closed `all_or_none` / `valid_prefix` / `independent` policies,
  `ac.multi_allocator`, `ac.age_select_k`, `ac.dependency_set`, and
  `ac.terminal_transaction`.
- A committed ReservationSet requires at least two resource owners and the
  exact same accepted mask on every owner, so no participating resource can
  accept a divergent lane mask.
- Policy, ordering, generation policy, and same-cycle reuse policy are closed
  sets. Lane widths are exact `!ac.var<iLanes>` in `[1, 64]`. No policy is
  inferred from source order, and the profile stays compiler-internal with no
  Python surface.

## Implementation

- ACIR adds six verified operations plus the `TransactionGroupPolicy` and
  `SameCycleReusePolicy` attributes. Each operation verifies exact lane width,
  closed policy values, age width agreement, winner bounds, and `i1`
  dependency readiness. Non-integer results now reject instead of
  dereferencing a null type: the `ac.dependency_set` ready check and the two
  pre-existing `ac.recovery.event` / `ac.kill_set` `i1` checks are guarded.
- The QueueGraph plan extracts one typed expression per endpoint and re-verifies
  lane count, operand widths, closed policy, committed-mask uniformity, and
  generation metadata fail-closed before any backend emission.
- gfsim C++, PYC, and RTL lower the same algebra: bitwise AND for reservation,
  a masked-equality select for all-or-none, a low-to-high `valid && reserved`
  prefix scan for valid prefix, popcount plus two lane-order prefix scans for
  the multi-allocator, an iterative `oldest_first` reduction for age-select-K,
  the exact identity-qualified dependency expression, and the conjunction of
  committed, effect-done, and terminal masks for completion.
- `compiler/mlir/lib/Emit/VerilogEmitter.cpp` also carries the selected-RTL
  instance rename from `rtl_*` to `comb_*` from this work item, and it now
  emits every instance in one globally name-sorted block. Selected primitives,
  submodule instances, and sequential primitives were previously emitted in
  three independently ordered sections, but
  `flows/tools/check_generated_rtl.py` compares the whole module body at once,
  so a submodule instance name such as `aa` sorts before a selected-primitive
  name such as `comb_x` and no section order can keep every pair ordered. Each
  instance is now rendered with the exact identifier it emits (sequential
  keys keep the `_inst` suffix and honor a memory `name` attribute; submodule
  keys use the `short_name`-before-`name` precedence and the assigned unique
  name), collected, and written in lexical order. Instance names are still
  assigned in IR order, so no identifier other than the `rtl_`→`comb_` rename
  changes; only the emission order is corrected.

## Reduced fixtures

The four-lane three-resource fixture proves:

1. one valid prefix is dispatched across three resource masks and cannot accept
   a divergent committed mask;
2. all-or-none and independent groups select lanes under their own policy;
3. both same-cycle reuse policies allocate within free capacity and take the
   lowest free slots first, including the case where the request exceeds the
   free capacity;
4. age-select-K retires the two oldest candidates with lower-lane tie-breaking;
5. the identity-qualified dependency set resolves and kills the matching lanes
   and reports exact zero-readiness;
6. the terminal transaction completes only where committed, effect-done, and
   terminal masks all cover the lane.

Every input field is randomized by a `splitmix64` generator, so all six
endpoints and all fifteen outputs are exercised. The previous odd-multiplier
LCG alternated bit zero on every draw, which pinned the reservation AND to zero
and silently dropped most of the algebra out of the fixture; the reference
oracle also modelled the allocator's accepted mask as the uncapped request
mask instead of the capacity-limited prefix the DUT computes. Both defects are
fixed, so the fixture now fails a design that over-issues free capacity.

The `transaction-algebra-scale.mlir` fixture re-emits the same algebra at eight
and ten lanes. It is compile/lint/audit coverage for width scaling and
deterministic ordering, not an executed semantic differential; the executed
semantic proof is the four-lane fixture.

The executable PYC fixture validates two hundred deterministic pseudorandom
inputs with random zero-to-four-cycle output stalls against the independent
oracle, and the Icarus fixture validates fifty seeded cases with the same
oracle.

## Known limits

- The gfsim C++ lowering generated by `acir-queue-cxxgen` is verified by
  inspection and compiles, but the executable differential oracle runs the PYC
  C++ path. Executed gfsim parity remains a framework-wide gap shared with the
  earlier stages.
- `ac.multi_allocator` `generation_bits` and `increment_on_allocate` are
  admission-verified plan metadata; materialized generation tags belong to the
  Decision 0279 versioned-identity contract.
