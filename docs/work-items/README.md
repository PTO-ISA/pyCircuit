# Modernization Work Items

This directory stores bounded work packets for the pyCircuit modernization
program. Project rules and state transitions are defined in
[Project Governance](../development/project-governance.md).

Name a packet `<milestone>-<task>-<short-name>.md` and include:

- objective and non-goals;
- request source, accepted contracts, decision IDs, and required approval;
- checkout, candidate identity, and relevant dirty overlay;
- complexity, dependencies, writable files, and integration owner;
- logical roles, actual models, and effort;
- acceptance criteria, independent oracle, rejection cases, and exact gates;
- current state, failures, evidence, rollback boundary, and remaining work.

Do not use a work-item state as product-decision or gate-status authority.
