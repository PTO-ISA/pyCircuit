# Independent reviews

Migration task packets and review logs are local ignored working records.
The refactor delivery cutoff was 2026-10-07. The current product scope is in
[the language reference](../reference/language.md) and the example catalog at
`examples/catalog.json`; removed historical cases do not count as verified.

Record bounded work and independent review in the PR or attach CI artifacts.
Use descriptive responsibility names instead of migration task numbers.
Keep exact commands, candidate identity, results and skipped checks in local
`docs/gates/logs/<run-id>/`. See [testing and gates](../development/testing-and-gates.md).
