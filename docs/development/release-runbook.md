# Release runbook status

The operational steps on this page belong to the retired ACC-only SDK release
route. They are not current dispatch instructions and must not be used to
publish an M5 candidate.

Decision 0283 records the accepted scalar source-unit contract, but candidate
verification is still in progress. A release runbook for the new SDK must be
bound to the candidate's approved manifest, platform jobs, installed-consumer
evidence, and upstream release authority before publication. This page does not
claim those gates have passed.

For current local build profiles see [M5 migration](m5-migration.md) and
[installation](../getting-started/installation.md). Follow
[repository management](repository-management.md) for upstream authority.
